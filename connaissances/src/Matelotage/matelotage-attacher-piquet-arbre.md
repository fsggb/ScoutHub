## Nœud de cabestan (demi-clé à capeler, nœud de batelier, nœud de fermier)
- **Usage** : fixer une corde à un piquet, un mât, un anneau ; démarrer ou finir un brêlage ; fermer un sac ; nœud intermédiaire d'une main courante. Se fait **d'une seule main** ; force ≈ 75 %. Facile à défaire : pratique pour modifier ou démonter un brêlage.
- **Méthode** : passer le bout autour du support, croiser sur le dormant, faire un second tour et coincer le bout sous la diagonale (il ressemble à un N). Rapide : faire deux boucles opposées, poser la seconde sur la première et en coiffer le piquet.
- **Limites** : sans traction constante, il se desserre tout seul ; l'**assurer par deux demi-clés**. Il peut mal réagir sous un gros effort ; ne jamais l'utiliser en bout de main courante sans le sécuriser. Il glisse si la traction change de côté ; avec une forte traction sur petite corde, faire une ganse.
- Disjoint, il donne le nœud d'échafaudage. Le nœud de cravate classique a la même forme.

## Tour mort et deux demi-clés
Un ou deux tours morts autour du support, puis deux demi-clés sur le dormant. **Extrêmement fiable**, polyvalent (fil à linge, tyrolienne, bateau, poutre, anse de récipient) ; ne se bloque jamais ; dicton marin : « un tour mort et deux demi-clés n'ont jamais lâché ». Pour plus de sécurité, passer la première demi-clé à travers le tour mort. Variante à demi-clés renversées, plus dure à défaire.

## Nœud de grappin (nœud d'organeau, nœud d'ancre)
Deux tours morts sur un anneau, puis le bout passe sous les tours (première demi-clé), puis une demi-clé. Meilleure façon de fixer un objet lourd ou une ancre ; l'usure par frottement est faible au point d'ancrage : recommandé pour les anneaux métalliques ou rouillés (barque). Force ≈ 75 %. Peut être impossible à défaire après forte traction.

## Nœud de bois (nœud d'anguille)
- Nœud coulant fait en enroulant plusieurs fois le bout sur lui-même autour de son propre dormant. Force ≈ 70 %. Se défait en tirant sur le bout.
- **Usages** : démarrer un brêlage (discret, on le noie sous les tours) ; haler un rondin ; ancrer à un arbre la faîtière d'une canadienne ou un fil à linge.
- **Avec barbouquet** (une demi-clé plus loin sur la pièce) : monter à la verticale un poteau, une planche ; tester en début de levage ; si la pièce est trop lisse, préférer un nœud de barreau d'échelle.
- **Interdit** comme ancrage d'une corde à nœuds ou d'une échelle (grand guide).

## Tête d'alouette
Fixer une corde sur une barre horizontale ; ranger un cordage sur un support ; accrocher les mailles d'un filet aux bois. Les marins disent « baguer ».

## Nœud de brigand (nœud de longe)
Boucle glissante faite de ganses successives : on le défait **d'une seule main** en tirant sur le bout. Attacher un cheval (longe ou rênes), un canot pneumatique, avoir une « troisième main ».

## Autres attaches
- **Nœud constricteur** : tours sur le support en passant deux fois sur le dormant puis dessous ; serre très fort (fermer un sac, maintenir). **Nœud étrangleur** : demi-clé puis passage par-dessus le brin gauche et derrière le croisement ; avec une boucle pour qu'il soit temporaire.
- **Nœud de traverse** : attacher deux bois ou bambous croisés (pagaies sur une galerie) ; se coupe sur le fil diagonal.
- **Nœud d'attache** (et attache renforcé) : accrocher un chalut, une monture, maintenir un rouleau de corde.
- **Amarrage à fouet** : fixer une petite corde sur une plus grosse ou sur un espar pour hisser des outils.
- **Nœud de tube** (AEDIS) : attacher une corde à une poutre ou un piquet.
- **Nœud de piquet** (grand guide) : ganse vrillée d'un tour et capelée sur le piquet (ruban de chantier).
- **Nœud de balai** : constricteur autour du manche et nœud droit (suspendre un balai).

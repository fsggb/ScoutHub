## Les sept nœuds de base (Budworth)
Utilisés par tous ceux qui manient des cordes, faciles à faire, à reconnaître et à défaire, même d'une main : **nœud plat, nœud de chaise, nœud d'écoute, nœud de pêcheur, demi-clé à capeler (cabestan), tour mort et deux demi-clés, nœud de bois**. Règle : toujours le nœud le plus simple qui convient (l'histoire de Jimmy Hicks, qui ajoutait toujours une clé de trop et fit perdre le canot de sauvetage).

## Pièges à éviter
- Nœud de vache au lieu du nœud plat ; nœud de chaise noué « à gauche ».
- Cabestan seul sans traction constante (il se desserre) ; nœud d'anguille pour ancrer une échelle ou une corde à nœuds (interdit).
- Nœud de tendeur pour un usage de sécurité (il glisse).
- Corde synthétique sans demi-clé de sécurité.

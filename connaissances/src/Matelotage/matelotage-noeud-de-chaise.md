## Nœud de chaise (p. 13)
Aussi appelé nœud d'agui, nœud de bouline, bowline.
- Boucle fixe au bout d'une corde : amarrer, hisser, porter, sauver quelqu'un, entourer un paquet. Simple, solide, sûr, ne glisse pas.
- Plus la charge est lourde, plus il se serre ; une fois détendu, il se défait facilement.
- Pour s'en souvenir : « le serpent sort du puits, fait le tour de l'arbre et rentre dans le puits ».
- Le bout doit rester à l'intérieur de la boucle ; avec une corde synthétique raide, l'assurer avec une demi-clé.

## Nœud de chaise double (p. 13)
- Soutenir quelqu'un suspendu dans le vide ou le long d'une paroi, en répartissant la charge sur deux boucles.
- À n'utiliser que sous la conduite d'un adulte formé. S'exercer d'abord au nœud de chaise normal.
- Rappel : un nœud de loisir ne sert jamais à assurer une personne sans adulte formé.

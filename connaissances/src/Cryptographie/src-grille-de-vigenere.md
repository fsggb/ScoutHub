## Contenu du document
Fichier intitulé « Grille de Vingère » (sic) dans « Documentation > Cryptographie ». Une seule page en tableau, colonnes :
1. **Morse** (A •-, B -•••, …) → `crypto-morse` ;
2. **Système de codage de Vigenère** : le carré de 26 lignes, chaque ligne étant l'alphabet décalé d'un rang (ligne A : A…Z ; ligne B : B…Z A ; … ; ligne Z : Z A…Y) → `crypto-vigenere` ;
3. **Braille** (A ⠁, B ⠃, …) → `crypto-braille` ;
4. **OTAN** (Alpha, Bravo, …) → `crypto-alphabet-phonetique-otan`.

Le document ne contient pas de mode d'emploi : seulement les tableaux. L'extraction de texte du carré est en partie désordonnée, mais toutes les correspondances morse, braille et OTAN sont lisibles.

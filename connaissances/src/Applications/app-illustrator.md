## À quoi sert VectorCraft
Logiciel libre d'illustration vectorielle (MIT/Apache, équipe ArtCraft / storytold) aux outils, menus, panneaux et raccourcis familiers d'Illustrator : plume, sélection directe, Pathfinder, repères commentés, Aspect, Nuancier, Calques. Le vectoriel s'agrandit sans perte. Usages scouts : logo ou écusson de patrouille, foulard, insigne, plan stylisé du camp, affiche, fichier SVG pour une découpe laser ou de la broderie.

## Ouvrir VectorCraft
- Dans ScoutHub : https://fsggb.github.io/ScoutHub/Illustrator/ (tuile « Illustrator », rubrique Création). Ce n'est pas Adobe Illustrator.
- Sans compte ; fichiers sur l'ordinateur. Interface traduite en français.

## Fonctions principales
- Outils de dessin et de tracés (plume, sélection directe…), booléens exacts (**Pathfinder**, **Concepteur de formes**).
- Peinture, dégradés, panneau Aspect, transparence ; nuances.
- Texte avec styles, chaînage, texte bidirectionnel (hébreu/arabe) ; texte vertical initial.
- Révolution 3D (initiale) ; 57 filtres d'effets de type pixel avec galerie d'effets.
- Exporter pour écrans ; impression ; assemblage (Package).
- Annulation illimitée.

## Pas à pas : écusson de patrouille
1. Ouvrir la tuile Illustrator, nouveau document.
2. Dessiner la forme de l'écusson (ellipse ou forme à la plume), l'animal totem avec la plume.
3. Combiner ou découper les formes avec Pathfinder ou le Concepteur de formes.
4. Remplir avec les couleurs de la patrouille (Nuancier), ajouter le nom (outil Texte).
5. Enregistrer au format natif `.vectorcraft`, exporter en SVG (vectoriel) ou PDF pour l'imprimeur, en PNG pour un réseau social.

## Formats
- Natif : `.vectorcraft` (JSON documenté).
- Import et export : **SVG**, **PDF**, `.ai` compatible PDF (y compris PDF/X), EPS, DXF, EMF/WMF ; export PNG, JPEG, WebP, PSD.
- Ouverture : SVGZ, modèles, GIF, TIFF, BMP, JPEG XL ; PSD/PSB (calques), anciens .ai version 7 ; documents Affinity (.af, .afdesign, .afpub…) en lecture.

## Limites
- Alpha (environ 65 % prêt pour un illustrateur courant).
- Échange de fichiers .ai réels encore imparfait ; 3D et matériaux limités ; pas de scripts ; pas de fonctions d'IA générative.

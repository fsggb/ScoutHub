## Lecture du tableau
- **p.** = page imprimée du carnet (page du PDF = p. + 2). Auteurs non indiqués dans le carnet ; un air est signalé quand le carnet l'indique.
- « Trad. » = chanson populaire ancienne dont les paroles complètes sont dans `chants-paroles-traditionnelles`. Ailleurs, seul le premier vers est cité.
- **Occasion** suggérée d'après le texte.

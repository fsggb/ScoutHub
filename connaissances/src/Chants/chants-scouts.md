## Lecture du tableau
- **p.** = page imprimée du carnet (page du PDF = p. + 2). Auteur et compositeur : non indiqués dans le carnet ; l'air est donné quand le carnet l'indique.
- Seul le premier vers est cité (droits d'auteur). **Occasion** : suggérée d'après le texte.

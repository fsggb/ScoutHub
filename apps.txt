# Applications assemblées sur le domaine de ScoutHub (https://fsggb.github.io/ScoutHub/<dossier>/).
# Chaque application reste dans son dépôt d'origine, SANS modification (ni nom, ni icône, ni script ajouté) :
# le déploiement va chercher la dernière version, chaque jour et dès qu'elle change (workflow « Synchroniser »).
# Format : <type> <dossier> <dépôt> [paramètre]
#   release : dernière version publiée du dépôt (archive web « <paramètre>-web-*.zip »), rapide, sans compilation
#   trunk   : compilation Rust → WebAssembly depuis le dernier commit du dépôt (<paramètre> = dossier de l'application)
#   excali  : compilation d'Excalidraw (Node) depuis le dernier commit
#   static  : dépôt de site statique cloné tel quel
# CathIA, ScoutMap, ChatGDB, SolidWorks (ScoutCAD), SoLeadWorks (ScoutCraft) et AutoCAD (ScoutDraft) se publient
# désormais SEULS (leur propre workflow, sur https://fsggb.github.io/<dépôt>/) : ScoutHub ne les clone/compile plus,
# le portail pointe directement sur ces adresses (même domaine : connexion partagée).
#   perl    : site pré-calculé par un script du dépôt (<paramètre> = chemin du script Python), régénéré chaque jour
